# Contributing to Jarvis AI Assistant

Thank you for your interest in contributing! Here's how you can help:

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR-USERNAME/Jarvis-AI-Assistant.git`
3. Create a feature branch: `git checkout -b feature/YourFeature`
4. Make your changes
5. Commit: `git commit -m 'Add YourFeature'`
6. Push: `git push origin feature/YourFeature`
7. Submit a Pull Request

## Code Style

- Use Java naming conventions
- Write clear, commented code
- Keep methods focused and testable
- Follow the existing project structure

## Adding New Commands

1. Add translation to `TanglishTranslator.java`
2. Add command logic to `CommandProcessor.java`
3. Test thoroughly
4. Update README.md with new command

## Reporting Issues

Please include:
- Clear description of the issue
- Steps to reproduce
- Expected vs actual behavior
- Your environment (OS, Java version, etc.)

## Questions?

Feel free to open an issue with the `question` label!
